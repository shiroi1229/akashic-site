TERMINAL / IMPLEMENTATION NOTES

この端末について

ゼロ地から、アカシックへ。

GitHub Pagesの独立したパスで公開している端末です。既存のトップ・小説・音声ページは維持しています。OpenAI Sitesへの配置ではありません。プレクサスなどの演出はフィクションで、X2や実サーバーの稼働状態を表すものではありません。

通信と保存

ページとキャラクター画像はこのサイトから、ギャラリーのサムネイルはYouTubeの画像配信元から読み込みます。YouTubeプレーヤーは接続ボタンを押した後に読み込みます。動きの設定だけを、このブラウザーのローカルストレージに保存します。このページ独自のアクセス解析や広告コードはありません。YouTubeなどの外部サービスでは各サービスの規約が適用されます。

掲載内容

入口の動画IDとタイトル、文字・音声の入口は既存の公式サイトをもとにしています。最新一覧との自動同期は未接続です。キャラクターは提供済み画像を使用し、新しい正典設定は追加していません。ギャラリーの画像は各動画のサムネイル更新に応じて変わることがあります。
